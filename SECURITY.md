# Segurança

Não publique vulnerabilidades em issues públicas. Ao encontrar um problema,
abra um aviso privado de segurança no GitHub quando esse recurso estiver
habilitado no repositório.

O RbxTools deve seguir estes princípios:

- solicitar elevação somente no momento de alterar o firewall;
- criar regras em um grupo exclusivo e identificável;
- nunca remover ou editar regras externas ao grupo do RbxTools;
- validar caminhos de executáveis antes de criar regras;
- manter uma ação clara de reversão.
